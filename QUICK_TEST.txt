🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Text still transparent after sphere
Solution:
  1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  2. Clear browser cache
  3. Try different browser
  4. Check console (F12) for errors

Issue: No haptics felt
Solution:
  1. Check Settings: Haptics/Vibration enabled
  2. Device must have vibration motor (iPhone 6s+, most Android)
  3. Desktop browsers don't have haptics (expected)

Issue: Modal doesn't open
Solution:
  1. Check console (F12) for JavaScript errors
  2. Verify PORTFOLIO/BLOG links exist
  3. Try hard refresh

Issue: Email submit shows error
Solution:
  1. Backend not set up yet (expected)
  2. Modal and validation still work perfectly
  3. Error message shows on screen (expected behavior)
